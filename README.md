### 🚀 Featured Projects

#### 🌌 AuroraLens — Real-time Aurora Visibility Prediction
**[Live Demo](https://auroralens.online)** | **[Repository](https://github.com/mosinmushtaq/aurora-kashmir)**

> A production-grade platform predicting aurora borealis visibility using live NASA OMNI satellite telemetry. Deployed and operational.

- **Ingests** real-time solar wind data from NASA's OMNI database.
- **Runs** a dual-stage XGBoost pipeline to predict aurora intensity and visibility windows.
- **Serves** predictions via Next.js frontend with MapLibre GL for geographic visualization.
- **Stores** 1+ year of historical predictions in Postgres for trend analysis.

*Tech Stack:* `Python (XGBoost, Pandas, NumPy)` `FastAPI` `Next.js` `PostgreSQL (Neon)` `MapLibre GL` `Vercel`
<br>

#### 🧬 AMR-Sentinel — Antimicrobial Resistance Prediction
**[Live App](https://amr-sentinel.streamlit.app)** | **[Repository](https://github.com/mosinmushtaq/AMR-Sentinel)**

> Tabular ML pipeline predicting antimicrobial resistance patterns from clinical microbiology data. Built during a hackathon; demonstrates end-to-end ML workflow from data exploration to deployment.

- **Preprocesses** clinical lab results and antibiotic susceptibility data.
- **Trains** ensemble models (XGBoost + Logistic Regression) with feature importance analysis.
- **Interactive Streamlit interface** for clinicians and researchers to predict resistance profiles.

*Tech Stack:* `Python (Scikit-learn, XGBoost, Pandas)` `Streamlit` `GitHub Pages`
<br>

#### 📚 RetractWatch — Retraction Detection in Academic Bibliographies
**[Repository](https://github.com/mosinmushtaq/retractwatch)**

> Full-stack application scanning academic papers' bibliographies against the Retraction Watch database in real-time. Built during Cursor Hackathon at NIT Srinagar.

- **LLM-powered** bibliography extraction from uploaded PDFs.
- **Real-time cross-reference** with Retraction Watch API.
- **Highlights** retracted papers and flagged authors.
- **Next.js + Convex backend** for scalable serverless architecture.

*Tech Stack:* `Next.js` `Convex` `LLM APIs` `TypeScript`
